# 前端组件与样式层规范

适用于 `frontend/` 的 UI 组件、BenchMark 视觉与样式。新增或修改界面组件、样式、布局前先读本层。

## 规范索引

| 规范 | 何时读取 |
|---|---|
| [组件与样式](./components-and-style.md) | 新增/修改组件、样式、布局、视口适配、动效、可访问性 |

## 开发前检查

- [ ] 颜色/间距是否引用 `--benchmark-*` 令牌，无裸 hex。
- [ ] 是否复用了 `src/components/ui/` 与 `src/components/shell/` 现有控件。
- [ ] 布局在 `1280x720` 是否无横向溢出、无裁切（高内容用可滚动容器）。

## 质量检查

- [ ] 交互有键盘焦点、可访问名称；表单错误有 `aria` 关联。
- [ ] 动效只用 opacity/transform 且被 reduced-motion 覆盖。
- [ ] 无默认组件库观感、无装饰性评分图表。
