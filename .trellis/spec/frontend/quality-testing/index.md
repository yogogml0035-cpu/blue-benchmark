# 前端质量与测试层规范

适用于 `frontend/` 的质量门、测试策略与 E2E 隔离后端。编写或审查前端测试、运行质量门前先读本层。

## 规范索引

| 规范 | 何时读取 |
|---|---|
| [质量与测试](./quality-and-testing.md) | 编写/运行测试、调整质量门、排查 E2E、改动依赖 |

## 开发前检查

- [ ] 质量门命令是否最新（typecheck/test/check:api/build/test:e2e）。
- [ ] E2E 是否走隔离后端与生产构建，不依赖开发库/`next dev`。

## 质量检查

- [ ] 单元/组件/浏览器三层覆盖新增逻辑。
- [ ] 认证断言反映真实后端行为，非模拟。
