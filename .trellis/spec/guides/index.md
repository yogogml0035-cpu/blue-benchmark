# 跨层与复用指南

这里只保留当前 Skill Eval Platform 会实际用到的跨包检查，不包含 Trellis CLI、事件日志、模板同步或其他仓库的案例。

## 指南索引

| 指南 | 何时读取 |
|---|---|
| [代码复用与所有权](./code-reuse.md) | 新增 Helper、Hook、共享组件、状态映射或发现重复逻辑时 |
| [跨层合同检查](./cross-layer-contracts.md) | 修改 API 字段、状态机、错误、授权、OpenAPI 或完整用户路径时 |

## 开始前

- [ ] 用 `rg` 找到相关字段、状态、错误码和现有所有者。
- [ ] 判断描述的是当前源码事实，还是尚未落地的未来计划。
- [ ] 列出 Backend Schema -> OpenAPI -> Feature Service -> 测试的同步点。

## 收尾

- [ ] 没有新增第二套 DTO、错误解析、状态文案或授权逻辑。
- [ ] `backend/openapi.json` 只由生成命令更新。
- [ ] 自动化、真实 AI 验收和文档证据没有相互冒充。
- [ ] 所有结论都能指回当前源码、测试、生成合同或明确标注状态的项目文档。
