# 构建场景绑定的评测用例上传 Skill

## Goal

在仓库 `skills/ai-eval-push/` 中提供可复用 Skill：从本地 Agent 当前可见上下文整理六类材料，经老师确认预览后，用场景限定凭证调用平台 API 创建待审阅评测用例草稿。

## Requirements

- Skill 只在用户明确要求沉淀/上传评测用例时执行真实上传。
- 从环境变量或用户级私密配置读取 API 地址和场景凭证，不保存明文秘密。
- 自动提取候选：标题、原始任务要求、参考输入、记忆材料、真实坏样本及反馈、标准答案。
- 任务要求、输入、记忆原文、反馈原话和标准答案不被静默改写或截断。
- 上传前展示完整结构化预览并取得明确确认；缺少标准答案或关键来源时继续追问。
- 使用稳定 `command_id` 支持安全重试；认证、撤销、限流、校验和网络错误给出可操作反馈。
- Skill 不读取已上传草稿，不生成规则，不发布，不跨场景指定 workspace。

## Acceptance Criteria

- [ ] Skill 目录通过官方快速校验，无占位内容。
- [ ] 确定性脚本能校验六类材料并调用连接状态/上传接口。
- [ ] 配置缺失、凭证无效、重复上传、payload 无效和成功均有测试。
- [ ] 真实本地 API 联调创建一份包含记忆材料的草稿，数据库/API 回读一致且不输出秘密或正文。
