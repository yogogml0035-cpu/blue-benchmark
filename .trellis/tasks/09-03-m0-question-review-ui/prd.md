# 实现题目列表与双栏审改

## Goal

完成评测集内题目浏览与完整审改工作台，让老师对照六类材料选择、修改或补充 AI 动态候选维度，保存后再独立发布，并安全处理重生成、重开和删除。

## Dependency

- 后端 Web 状态合同、Next.js 壳层认证、评测集详情均已合并并在 `main` 复验。

## Requirements

- 当前评测集内使用紧凑题目列表，展示标题、状态、维度数、更新时间和下一步动作。
- 支持标题搜索、状态筛选和最近更新优先；约 200 项不卡住，不预取详情。
- 详情为独立全页双栏：左侧六类材料，右侧状态与维度；两个正式桌面视口无跳动或溢出。
- 记忆材料默认折叠并标注自动筛选边界；全部材料在显式编辑模式可纠正。
- 材料提交只有“保存并重新生成”，旧维度失效；标题单改不生成；stale 不覆盖草稿。
- 生成中可见轮询，失败可重试；后台错误经过清洗。
- AI 按材料动态产生 2–6 个两字段候选，首次全部未选。
- 老师可选择、取消、修改、删除和手工新增维度，设定 0–10 整数通过分；最终 1–20 项。
- 保存前可撤销，离开脏草稿提醒；保存后未选项永久丢弃且 confirmed=true。
- 保存与发布分离；未保存 AI 初稿不能发布。
- 已发布题可重新打开审改；材料改动走重新生成；无历史版本。
- 按状态执行硬删除门禁，曾发布题重开后要求标题二次确认。

## Acceptance Criteria

- [ ] 200 项列表搜索、筛选、稳定排序、空结果和详情按需加载正确。
- [ ] 六类材料阅读/编辑、记忆折叠、取消、保存并重新生成和 stale 草稿保护通过。
- [ ] generating/failed/pending-unconfirmed/pending-confirmed/published 各状态显示正确动作，轮询进入终态停止。
- [ ] AI 候选首次全未选，0 项不能保存或发布；Fake 固定结果不作为真实验收。
- [ ] 老师可手工新增，1–20、ID、criterion 与 0–10 校验正确。
- [ ] 保存后只保留最终项并保持待发布；发布失败不丢保存结果。
- [ ] 重开保留材料/维度，清除发布态；再次保存/发布成功且无历史版本。
- [ ] 生成中、普通未发布、已发布/曾发布的删除规则均由 API 和 UI 同时覆盖。
- [ ] Chrome 完整与 Safari 核心流程、两个桌面视口、长内容和 20 维度通过。

## Out Of Scope

- 手工新建题目、全部题目入口、服务端分页。
- `name` 字段、雷达图、实际评分、候选历史、版本和回收站。
- 移动端与公网部署。
