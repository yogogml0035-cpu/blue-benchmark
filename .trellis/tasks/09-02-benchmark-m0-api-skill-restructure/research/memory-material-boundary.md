# M0 记忆材料边界

## 新增目的

很多本地 Agent 会在执行任务时读取用户长期偏好、历史规则或项目记忆。若评测用例只保存任务要求和参考文件，却遗漏这些实际输入，未来复现时可能错误归因：结果差异可能来自记忆缺失，而不是被评 Skill 退化。

因此评测用例从五类材料扩展为六类，新增“记忆材料”。

## 已确认边界

- 只记录此次任务中本地 Agent 实际读取到的记忆。
- 不扫描或上传整个记忆库。
- 不上传未在此次任务使用、仅被认为“可能相关”的记忆。
- 不上传其他任务、其他用户、凭证、内部 Agent 状态、本地主机路径或存储索引。
- Skill 负责识别候选并在上传预览中单独展示；老师确认后才上传。
- 本次没有读取记忆时允许为空，并明确记录“未使用记忆”。

## 为什么不能与参考输入合并

- 参考输入是老师为当前任务提供或指定的材料。
- 记忆材料是 Agent 从持久上下文中额外取用的用户偏好或历史规则。
- 两者来源、授权和复现意义不同。合并后无法判断未来运行缺失的是业务资料还是用户偏好。

## 仍需确认

记忆材料保存形态尚未确定：保存本次读取到的原始记忆条目，还是保存 Agent 提炼且经老师确认的任务相关偏好摘要。该选择会影响复现保真、隐私、内容体积和跨 Agent 兼容性。
