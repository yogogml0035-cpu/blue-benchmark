# 实现评测集与凭证管理界面

## Goal

在 AURA AppShell 中完成评测集文件夹与上传凭证的真实管理，让管理员创建评测集后通过一段提示词把上传 Skill 绑定到该评测集。

## Dependency

- 后端 Web 合同与 Next.js 壳层/认证子任务均已合并并在 `main` 复验。

## Requirements

- 评测集文件夹卡片展示名称、描述摘要、题目数和连接状态，颜色由 scene ID 稳定派生。
- 支持创建、改名、修改描述；只允许删除空评测集，删除提示凭证同步失效。
- 评测集详情展示凭证数量、脱敏生命周期和最近使用时间。
- 凭证只在管理员显式点击后签发；支持轮换全部有效凭证和撤销单个凭证。
- 签发/轮换后只显示一次包含本地服务地址和长期凭证的 Agent 绑定提示词。
- 提示词要求 Agent 安全保存、配置 `ai-eval-push` 并运行 connection；网页不展示多套人工配置教程。
- 明文不进入 URL、Web Storage、持久缓存、日志或测试 artifact；关闭/刷新后不能恢复。
- Chrome 完整支持复制；Safari 复制失败时提供手动选择 fallback。

## Acceptance Criteria

- [ ] 20 个评测集文件夹在两个桌面视口稳定、可扫描且刷新后颜色不变。
- [ ] 创建/编辑/空删和同名、非空、404、401 错误均来自真实 API 并正确呈现。
- [ ] 创建评测集不会自动签发凭证。
- [ ] 签发、轮换、撤销和四种连接状态准确；轮换后旧凭证不能连接。
- [ ] 提示词中服务地址和 token 正确，token 恰好出现一次，安全指令完整。
- [ ] 提示词只显示一次；关闭/刷新后不恢复，浏览器存储、URL、日志、trace 和报告无 token。
- [ ] Chrome 与 Safari 核心流程通过，剪贴板失败不会静默。
- [ ] 前后端测试、类型检查、构建、OpenAPI 漂移和 `git diff --check` 通过。

## Out Of Scope

- 网页直接修改用户机器或自动发送提示词给 Agent。
- 短时绑定码、凭证明文恢复、多管理员和公网连接。
- 题目列表、材料和维度审改。
