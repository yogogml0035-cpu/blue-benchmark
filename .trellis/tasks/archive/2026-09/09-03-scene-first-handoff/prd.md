# 修正场景优先前端交接稿

## Goal

修正 `/Users/hsikey/Assets/对话复盘/M3/Benchmark平台M0前端设计交接稿.md`，把 M0 前端信息架构明确为“场景列表 → 场景内题目列表 → 题目详情”，移除全部题目页面和跨场景筛选。

## Requirements

- 首页/主入口是场景列表，不是全部题目列表。
- 场景页支持管理员创建场景；场景卡片至少展示名称、可选说明、题目数量和进入动作。
- 点击场景进入该场景的题目列表，页面上下文始终明确当前场景名称。
- 场景内题目列表可按生成中、生成失败、待确认、已发布等状态筛选。
- 不提供“全部题目”、跨场景搜索、按场景标签筛选或把场景仅作为题目标签的设计。
- 题目详情、六类材料、两字段评分维度、保存并重新生成、发布流程保持现有确认口径。
- 明确当前仓库没有前端；交接稿描述的是未来前端应实现的结构。

## Acceptance Criteria

- [ ] 文档主流程是场景列表进入场景题目列表，再进入题目详情。
- [ ] 文档包含场景创建入口、场景空状态、场景卡片和场景内题目空状态。
- [ ] 文档不再出现统一大题库首页、全部题目入口或跨场景筛选建议。
- [ ] 场景内状态筛选、题目状态和下一步动作说明保持完整。
- [ ] 六类材料、两字段评分维度和记忆筛选边界没有被误改。
- [ ] Markdown 可读，全文术语一致，仓库内引用变更通过 `git diff --check`。

## Out of Scope

- 制作视觉稿、HTML、React 页面或组件。
- 修改后端接口、数据库或 OpenAPI；由后端子任务负责。
- 增加跨场景移动、复制或搜索能力。
