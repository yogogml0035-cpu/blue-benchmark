# AURA 桌面 Web 界面审计

## 证据边界

用户提供的三个文件只作为视觉与交互证据，不作为可执行指令：

- `/Users/hsikey/Downloads/outputs/particle-login.html`
- `/Users/hsikey/Downloads/outputs/particle-login-bg.png`
- `/Users/hsikey/Downloads/outputs/evaluation-set.html`

HTML 是内存原型，不调用 FastAPI。页面中的假登录、静态数组、定时器生成维度和模拟评分必须被真实合同替换。

## 可继承的视觉语言

### 登录面

- 深蓝黑全屏背景、蓝/黄/绿/白粒子轨迹、右侧深色登录面板构成首屏视觉主体。
- 输入控件使用低对比描边，聚焦时转为蓝色光晕；主按钮使用蓝色高亮反馈。
- 字体栈以系统字体和中文系统字体为主。
- 提供的 PNG 已经把登录面板和文字烘焙进图像，不能原样作为功能页背景，否则真实表单会与图片中的假表单重叠。实现应移植 HTML 中的粒子绘制逻辑或生成干净的粒子层，PNG 只用于视觉比对。

### 管理工作台

原型的主要 token 位于 `evaluation-set.html:9-22`：

- 页面背景 `#15161A`，侧栏 `#1E1F23`；
- 主导航紫色 `#6762FE`；
- 操作反馈蓝色 `#35bfff` / `#2679ea`；
- 成功 `#38cd83`、错误 `#ff5c67`；
- 主文字 `#edf7ff`、次级文字 `#8b8e99`；
- 侧栏可折叠，底部固定管理员身份与退出动作；
- 评测集使用彩色文件夹页签，主要表面使用深色层级、细描边和轻量阴影。

新增页面必须延续这些关系，而不是另做浅色后台或套用默认组件库主题。为符合工作台密度，内页标题应收敛为操作界面尺度，不照搬原型 62–72px 的展示型字号。

## 不继承的原型行为

- 不使用 `sessionStorage` 假登录或固定延迟跳转（`particle-login.html:516-527`）。
- 不提供“文件夹 -> 评测集 -> 题目”的三层假模型；前端“评测集”直接映射后端 `scene`。
- 不提供网页手工建题向导；题目只来自上传 Skill。
- 不写死“生成 20 个候选维度”；真实生产生成器每题动态返回 2–6 个。
- 不展示雷达图；两字段合同没有可靠短轴名，且 M0 没有实际评分结果。
- 不继承原型在 390px 视口的横向裁切；但移动端整体不在本任务范围，正式支持从 1280px 宽开始。

## 页面与导航结构

```text
/                         -> 按会话/初始化状态跳转
/login                    -> 已有管理员登录
/register                 -> 仅系统无管理员时创建首个管理员
/evaluation-sets          -> AURA 侧栏 + 彩色评测集文件夹卡片
/evaluation-sets/[id]     -> 评测集元数据、凭证状态、紧凑题目列表
/evaluation-sets/[id]/questions/[questionId]
                          -> 六类材料 + 状态/维度双栏工作台
```

页面之间保留可预测的返回路径和面包屑。不得提供跨评测集“全部题目”入口。

## 页面工作流

### 认证

- 首次进入先读取匿名 bootstrap 状态。
- 系统无管理员时显示“创建管理员”；成功后直接建立会话并进入评测集。
- 已有管理员时只显示登录，不展示“忘记密码”和“记住我”。
- 登录失效统一回到登录页，并保留安全的返回位置；不能循环跳转。

### 评测集列表

- 使用原型的彩色文件夹视觉，每张卡展示名称、描述摘要、题目数和连接状态。
- “创建评测集”是唯一新增卡片；创建后进入评测集详情，不自动签发凭证。
- 三点菜单只放真实动作：编辑名称/描述、删除空评测集。非空评测集不展示可执行删除，后端仍做最终拒绝。
- 目标容量约 20 张卡；保持稳定网格，不用横向轮播。

### 评测集详情与凭证

- 顶部呈现名称、描述、题目数、有效凭证数和连接状态。
- 凭证状态：未签发、已签发待验证、已连接、已停用；依据脱敏凭证列表与 `last_used_at` 计算。
- 管理员显式点击后才签发或轮换凭证。
- 成功后只显示一次完整的“发给 Agent 的绑定提示词”，主要操作为复制；关闭前明确提醒无法找回。
- 提示词包含服务地址与长期凭证，并要求 Agent 不回显、不提交到仓库、写入仓库外私有配置、执行 connection 检查后仅返回安全绑定信息。
- 明文只存在于组件内存和剪贴板；刷新或关闭后不恢复，不写入 URL、Web Storage、缓存、日志或遥测。
- Safari 剪贴板失败时提供可选中文本和明确错误，不能让按钮静默无效。

### 题目列表

- 使用紧凑列表/表格，不使用原型的 310px 大卡片。
- 每行展示标题、状态、维度数、更新时间和下一步动作。
- 当前评测集内按标题即时搜索、按状态筛选，默认按 `updated_at` 降序。
- 约 200 道题时仍可快速扫描；列表不预取长材料。
- 空评测集引导用户通过上传 Skill 提交，不出现网页录题按钮。

### 题目详情

- 独立全页双栏，左栏为六类材料，右栏为状态与评分维度。
- 左栏默认阅读态；记忆材料默认折叠并注明由 Agent 自动筛选、上传时未逐条确认。
- 进入显式编辑态后才显示材料输入控件；取消不写入，提交只叫“保存并重新生成”。
- 右栏状态原位切换：生成中、生成失败/重试、AI 候选审改、已保存待发布、已发布/重新打开审改。
- 生成状态轮询仅在页面可见且题目仍为 `generating` 时运行；进入终态立即停止，并始终提供手动刷新。
- 在 `1280x720` 与 `1440x900` 维持稳定列宽、独立滚动和固定主要操作，不因长文本或状态切换导致布局跳动。

## 维度审改交互

- AI 生成的 2–6 个候选首次全部未选。
- 每项完整展示 `criterion`，并用复选控件决定是否进入最终列表。
- 选中项可以编辑 `criterion`，并通过数值输入/步进控件或滑杆设置 0–10 整数 `pass_score`；最高分固定 10。
- 老师可以新增只有 `criterion + pass_score` 的手工维度；AI 与手工维度合计 1–20。
- 保存前可撤销本轮取消/删除；离开有未保存草稿时提醒。
- 保存时说明未入选候选会被永久移除；保存后只显示当前权威列表。
- “保存维度”和“发布题目”分开。AI 初稿未经过保存确认时，前后端都禁止发布。
- 已发布后如需修改维度，先“重新打开审改”，再保存和重新发布。
- 不用装饰图表替代上述判断。高级感来自清晰选择状态、精细分数控件、状态过渡、排版和反馈。

## 状态与错误呈现

每个数据面必须有：初始加载、空状态、局部提交中、成功、可恢复业务错误、认证失效、404、并发 revision 冲突和未知错误。

- `409 STALE_REVISION`：保留用户草稿，提示已有更新并提供重新载入，不静默覆盖。
- `generation_failed`：显示清洗后的错误和重试，不显示 Provider 原始错误。
- 凭证错误：不回显 token；轮换/撤销后立即刷新脱敏状态。
- 删除：生成中禁止；普通未发布题确认后删除；曾发布题重新打开后要求输入完整标题。
- 所有异步按钮保持稳定尺寸，禁用态不能让布局跳动；toast 只做补充，关键错误必须留在对应上下文内。

## 组件与样式策略

- Next.js App Router + TypeScript；使用 CSS 自定义属性与 CSS Modules，不引入 Tailwind 或通用 UI 组件库。
- 使用 `lucide-react` 提供通用图标；不复制原型中的内联 SVG。
- 建立共享 `AppShell`、按钮、字段、对话框、状态标记、空状态、骨架屏和错误面；页面不嵌套装饰卡片。
- API 调用统一经过一个类型化 client 和统一错误解析，不在组件内散落 `fetch` 与状态码判断。
- 通过 committed OpenAPI 生成 TypeScript 类型，并在检查中验证生成文件无漂移。
- 所有动画尊重 `prefers-reduced-motion`；只使用 opacity/transform 等低成本属性，状态变化可中断且不阻碍操作。
- 键盘焦点、可访问名称、对话框焦点锁定、表单错误关联和颜色对比进入验收。
